Bersatu es un proyecto de desarrollo de software orientado para el Buffet Vegetariano Tien Lan Zu Shi de inspiración  Malasia ubicado en Jinotepe, Carazo. Actualmente el buffet continúa realizando sus principales gestiones de manera manual, incluyendo el registro y control de ventas, inventario, platillos, clientes y demás procesos administrativos. Esta situación puede generar dificultades en la organización de la información, el seguimiento de las operaciones y el acceso oportuno a los datos del negocio.

A partir de esta necesidad surge la propuesta de desarrollar un sistema que permita automatizar y centralizar estos procesos, brindando una herramienta tecnológica que facilite la gestión de las operaciones del buffet. El sistema contempla funcionalidades para administrar ventas, platillos, inventario, clientes, usuarios e historial de transacciones, además de contar con mecanismos de autenticación para gestionar el acceso de los usuarios.

Como estudiantes, nuestro propósito es aplicar los conocimientos adquiridos en el área de desarrollo de software para proponer una solución que responda a las necesidades identificadas en el buffet. El proyecto busca contribuir, mediante la tecnología, a que sus procesos puedan realizarse de manera más organizada, eficiente y segura, dejando una base preparada para una futura implementación del sistema en el negocio.
